AI / ML · Web App
FASHION TREND ANALYZER
Full-stack fashion analytics web app using Flask, applying 4 data mining algorithms (K-Means, Apriori, Logistic Regression, Time-Series) across 3 real-world retail datasets totalling 600K+ records (women's clothing e-commerce, online retail, fashion style data). Integrated the Google Gemini Vision API for real-time outfit image analysis, extracting 6 fashion attributes and mapping them to data-driven market insights, presented in a single-page dashboard with dynamic, live chart rendering.
